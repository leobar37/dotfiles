## Browser And Upload Safety

- Use the user's real Brave session when asked to use the authenticated browser.
- Do not substitute a fresh hidden browser for YouTube Studio or LinkedIn.
- Before changing visibility, verify the exact video ID, title, thumbnail, description, checks, and current visibility.
- Stop if YouTube shows warnings, restrictions, copyright claims, community guideline issues, or unusual processing errors.
- YouTube does not let creators replace a video file while keeping the same URL. A corrected render must be uploaded as a new video.
