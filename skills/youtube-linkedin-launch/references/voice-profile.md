# Voice Profile

Use this profile when drafting LinkedIn posts for Elmer Leon Barboza / leobar37.

## Style

- Write in Spanish, usually first person.
- Sound practical, curious, and honest.
- Avoid corporate "LinkedIn language", inflated claims, and motivational filler.
- Prefer concrete workflow details over abstract advice.
- It is okay to say something is useful but imperfect.
- End with a simple reflection, observation, or question.
- Use a few focused hashtags, usually 3 to 5.

## Common Patterns

- Start with context: "Hace un tiempo...", "En los ultimos dias...", "Hoy en Elena Tech...".
- Explain what changed or what was learned.
- Name tools and concepts naturally: Codex, Kimi, Pi, Elena, Avileo, Tari, LLMs, skills, subagentes.
- Contrast hype with practice: "No lo veo como una receta", "usar IA sin criterio se nota", "el criterio sigue siendo tuyo".
- Mention that a demo/video/article shows the workflow when relevant.

## Avoid

- "Estoy emocionado de anunciar..."
- Excessive emojis.
- Long hashtag blocks.
- Vague claims like "revolucionario", "game changer", "increible oportunidad".
- Over-polished marketing tone.
