# YouTube Launch Checklist

## Metadata Priority

1. Thumbnail: readable, high contrast, aligned with the promise.
2. Title: searchable, specific, and not clickbait.
3. First description paragraph: repeat the main topic and value clearly.
4. Chapters: keep accurate timestamps.
5. Hashtags: 3 to 5 visible hashtags.
6. Tags: secondary; use variants, misspellings, English/Spanish terms, and tool names.

YouTube's own UI explains that tags are useful mainly when users commonly misspell the content. Do not over-optimize tags at the expense of title, thumbnail, and description.

## Before Publishing

- Confirm the target video ID.
- Confirm current visibility and intended final visibility.
- Confirm title, description, thumbnail, and tags are correct.
- Confirm copyright checks show no problems.
- Confirm Community Guidelines checks show no problems.
- Stop if YouTube shows any warning, restriction, claim, or unusual processing message.

## Safe Publish Flow

1. Open YouTube Studio in the authenticated browser.
2. Open the exact video by ID.
3. Apply metadata changes.
4. Save if Studio does not autosave.
5. Visit Checks/Comprobacion inicial and confirm clean results.
6. Open Visibility/Visibilidad.
7. Select Publico only when explicitly requested.
8. Save.
9. Verify the video appears as Publico in Studio.
10. Open the public video URL and confirm it loads.

## Recommended Tags Pattern

Use a comma-separated set like:

```text
main topic, main topic IA, common misspelling, prompt engineering, agentes IA, agentes de codigo, AI agents, coding agents, agent loops, Codex, Claude Code, Kimi, skills, subagentes, planner, code review, workflow IA, validacion, LLM, AI coding
```
